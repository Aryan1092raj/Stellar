GEOLEDGER QUICK REFERENCE
=========================

Local URLs
----------
Frontend:    http://localhost:3000
Backend API: http://127.0.0.1:4000
Health:      http://127.0.0.1:4000/health

Start
-----
./start.sh

Or run manually:

cd backend && npm run dev
cd frontend && npm run dev

Stop dev servers:

pkill -f "ts-node-dev"
pkill -f "next dev"

Build and Test
--------------
cd backend && npm run build && npm test
cd frontend && npm run build && npm test
git diff --check

Database
--------
cd backend && npx prisma migrate dev
cd backend && npm run seed:ngos
cd backend && npm run import:ngos -- --file data/indian-ngos.sample.csv --source ngo-darpan --dry-run

Contract Scripts
----------------
./scripts/deploy_phase1_testnet.sh
./scripts/deploy_contracts.sh

Production Checks
-----------------
- NODE_ENV=production
- JWT_SECRET is strong and not a dev fallback
- DISABLE_EMAILS is not 1 in production
- ALLOWED_ORIGINS contains only real frontend domains
- DATABASE_URL is present and migrations have run
- Backend /health returns db: ok
- Frontend env has public Soroban/Firebase values
- Freighter browser test produces a Stellar Expert transaction link
